# ADR-0003：基础词库选 Rime luna_pinyin，且不进 git

- **状态**：已接受
- **日期**：2026-10-21
- **决策者**：用户
- **依据**：`docs/base-lexicon-eval.md`（实测数据）

## 背景

需要一份"开箱能打常用中文"的基础词库做冷启动。候选有 Rime `luna_pinyin`、CC-CEDICT、jieba 词典三种组合。

实测结论：
- **luna_pinyin**：约 5–6 万条，**带输入法调校过的词频**，拼音已按音节切分。许可 LGPL-3。
- **CC-CEDICT**：约 12 万条，覆盖广但**完全没有词频**，且 CC BY-SA 有传染性。
- **jieba 词典**：34.9 万行、MIT，但拼音覆盖率仅 13.1%（词频 ≥1000 时也只有 36%），多音字大面积注错，长尾噪声多。

## 决策

1. **采用 luna_pinyin** 作为 M0 基础词库。
2. 词库**不提交进 git**，作为独立资源包分发：自带 LICENSE 与来源说明，用户可替换。
3. 引擎只认统一的自有格式（TSV：`词 \t 拼音 \t 词频`），产地无关。

## 权衡

- 放弃：仓库"开箱即用"的便利（需要额外一步准备词库）。
- 换来：许可证决策可推迟到发布前；换词库不动一行引擎代码。

## 后果

- LGPL-3 数据以独立文件分发、可替换、附许可说明，视为聚合，**不强制主程序采用 LGPL**；主程序仍可选 MIT/Apache。
- 发布前必须复核：随包/下载的 `LICENSE-luna-pinyin` 存在且署名正确。
- 若发布时对 LGPL 有顾虑，降级方案是 jieba（词频 ≥100 约 3 万条）+ 多音字表合并，成本约 1–2 周。
