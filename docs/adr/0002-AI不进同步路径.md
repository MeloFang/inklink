# ADR-0002：AI 永不进入同步候选路径

- **状态**：已接受
- **日期**：2026-10-21
- **决策者**：用户 + Agent

## 背景

产品要"AI 优化候选排序"。但候选刷新受 50ms 预算约束（A1 公理），而本机实测的本地模型 `qwen3:14b` 单次生成 300ms 起，API 更慢。上一版的 `onActivate` 同步建库 11 秒卡死宿主，是同一类错误。

## 决策

1. **候选排序不用大模型**：用特征（词频、个人权重、时间衰减、拼音完整度、上下文二元组）。
2. 大模型只做"用户愿意等"的任务：续写、翻译、段落优化。
3. 所有 AI 调用**异步 + 可取消 + 超时降级**（1.5s 无首字即放弃，不提示）。

## 权衡

- 放弃：用大模型直接给候选打分的"聪明感"。
- 换来：打字永不卡顿；AI 挂了不影响输入。

## 后果

- 排序质量的提升靠特征工程与使用反馈，不靠模型。若将来要上 rerank 模型，必须是**本地小模型（<20MB）且同步耗时 <20ms**，并留下基准数据。
- AI 结果永远出现在"预测气泡"里，绝不能覆盖候选列表。
