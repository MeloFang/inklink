# ADR-0008：浮条进宿主进程，去掉常驻 UI 进程

- 状态：已接受
- 日期：2026-10-29
- 相关：[ADR-0007 加常驻 UI 进程与全局状态](0007-加常驻UI进程与全局状态.md)（其第 2 条「常驻 UI 进程」被本 ADR 取代）

## 背景

ADR-0007 决定加一个常驻的 `inklink-ui.exe`（浮条 + 托盘 + 设置台入口）。上线后
用户明确不认可（m09104）：「为什么不能和搜狗一样，切换到就会自动出浮动窗，而不是
还有一个程序在里面挂着」。

排查本机搜狗的实际做法后确认：搜狗的 `SoPY_Status`（浮条）、`SoPY_Comp`（候选窗）
是**每个宿主进程各画一份**（chrome / Weixin / explorer / Doubao / et 各自一个窗口），
并没有一个独立进程在画浮条；搜狗常驻的 `SogouCloud.exe` / `SogouImeBroker.exe` /
`SOGOUSmartAssistant.exe` 都不画浮条。

## 决定

浮条改由 `inklink_tsf.dll` 在**宿主进程内**自绘：

- `Activate` / `ActivateEx` → `bar::show()`；`Deactivate` → `bar::hide()`。
  切到本输入法才显示，切走即隐藏（同一时刻只有聚焦应用的浮条可见，正好对上
  ADR-0007 里担心的「五个窗口五个浮条」—— 实际上不成立，因为只有聚焦的那个在显示）。
- 删掉 `tsf/src/ui_notify.rs`（原来靠 `PostMessageW` + 注册表 `ShowSeq/HideSeq` 通知
  外部浮条进程，还踩过 UIPI：管理员启动的浮条收不到普通进程的 `WM_APP+12/13`）。
- 删除 `inklink-ui.exe` 的构建、部署、开机自启；`ui/` crate 源码留在 git 作为回退，
  不再进入打包。
- 浮条窗口类 `inklink-bar`（原外部版是 `inklink-ui-bar`），`WS_POPUP` +
  `WS_EX_TOOLWINDOW | WS_EX_TOP | WS_EX_NOACTIVATE`，右下角默认再上移 44px 避让搜狗。
- ☰ 菜单继续自绘（`tsf/src/menu.rs`，从 `ui/src/menu.rs` 移植），去掉「开机自启」和
  「退出浮条」两项（进程内没有"退出"这回事）。

## 为什么选这条（而不是"按需拉起浮条进程，空闲退出"）

用户要的是"用的时候别有一个程序常驻"。方案 B（切到输入法才拉起 `inklink-ui.exe`、
空闲 N 秒退出）被否，理由：

1. 用户**用的时候**进程照样在，没解决诉求。
2. 冷启动 100–300ms 延迟，快速 Alt+Tab 时忽隐忽现。
3. 空闲退出时机难定，回来那一下有延迟。
4. 多应用并发 `Activate` 都抢拉起 → 单实例竞态（实测曾堆出 5 个浮条进程）。
5. 托盘图标反复加/删像故障，删掉又丢「退出」入口。
6. 频繁启停留下僵尸进程记录（`Threads.Count==0`、路径为空的已终止进程）。

## 代价与护栏

DLL 里多了一个窗口 + 一套 GDI 自绘，风险集中在"别把宿主进程搞崩"：

- `tsf/Cargo.toml` 的 `[profile.release] panic = "abort"` 使 `catch_unwind` **失效**，
  所以 `bar.rs` / `menu.rs` 必须写 **panic-free 代码**（无 `unwrap`/`expect`/越界，
  wndproc 里不 panic）。
- 点击处理「先写注册表、再靠消息循环重绘」，不做 IPC、不起线程、不碰词库。
- 自绘菜单 `popup()` 里 `PeekMessageW` **只按菜单 hwnd 过滤**，且没有
  `std::process::exit`（原来外部 exe 版会 `exit`，进程内会杀掉宿主）。
- 纯函数（`scale` / `item_rects` / `hit_test` / `row_at` / `menu_size`）补了单测，
  `cargo test --release` 64 项全绿。
- 状态仍放注册表（ADR-0007 第 1 条不变），但现在由 DLL 在进程内**直接写**，切换后
  下一次按键即生效，没有跨进程通知的延迟与 UIPI 问题。

## 落地顺序

1. `tsf/src/bar.rs`（浮条）+ `tsf/src/menu.rs`（菜单）新建，接线 `Activate/Deactivate`。
2. 删 `tsf/src/ui_notify.rs`；`lib.rs` 的 `mod ui_notify;` → `mod bar; mod menu;`。
3. `tools/deploy-local.ps1` / `installer/install.ps1` / `tools/release.ps1` 去掉
   `inklink-ui.exe` 的构建/部署/自启（`uninstall.ps1` 保留清理逻辑给老安装用）。
4. 部署 1.1.10，`inklink-ui.exe` 与 `HKCU\...\Run\inklink-ui` 自启项删除。

> 版本 1.1.10 起生效。已加载旧 DLL 的宿主进程要重启一次才用上 1.1.10。
