# inklink Logo 使用规范

> 依据素材：用户提供的 `ink` 手写字 + 深蓝色椭圆底图像（对话附件，2026-10-29）。
> 本规范只描述**如何使用这份原始图像**，不包含任何重绘、改色、补元素或变形方案。
> 规则中的数字全部来自对该文件的实测（见第四节「检查结果」），不是估计值。
> 未明确的场景、尺寸、格式一律列入 **1.3 待确认信息**，确认前不得产出。

### 1.2 由实测得出、影响使用的三个事实

1. **背景是白色实底，不是透明底。** 把文件贴到非白色背景上会露出白色矩形；裁到椭圆外接框后仍会露出椭圆四角的白色三角（深灰底实测见 `_probe-dark-bg.png`）。因此底色规则见 2.4。
2. **图像带压缩噪点，不是纯平色。** 椭圆外区域（上下两条 633 px 宽的边带，隔 3 px 取样）统计到 7 种颜色；椭圆内部"纯色"区（x 120–480、y 70–100，共 360 × 30 px）统计到 943 种颜色。均是压缩产生的近色抖动，因此**不得放大使用**（见 2.2），否则噪点与色带会被放大到可见。
3. **原始画布的白边四边不等宽。** 直接把 633 × 448 的整张图当 logo 使用，视觉中心会偏。使用前必须按 2.1 裁切。

## 二、使用规则

以下每条都是可执行动作；括号内是判定方法。

### 2.1 素材准备（每次使用前先做这一步）

1. 从 `docs/brand/inklink-logo.png` 复制一份工作副本，**不改动原文件**。
2. 裁切到椭圆外接框，裁切框固定为：左 89 px、上 57 px、右 516 px、下 419 px（宽 427、高 362）。裁切只允许"切边"，不允许缩放或重采样。
3. 裁切后必须复核：宽高比 = 1.18 : 1（±1%），椭圆四边紧贴画布边缘、无残留白边。
4. **裁切不会去掉椭圆四角的白色**：这是椭圆内接于矩形的必然结果（实测裁切图四角像素为 254/255 的近白色）。因此裁切后的文件仍然只能用于白底/浅底，见 2.4。
5. 裁切是唯一允许的图像处理动作。除此之外的任何像素修改都属禁止项（见第三节）。

### 2.2 尺寸与缩放

1. 缩放必须**等比**：宽高比恒定 1.18 : 1，宽度变化时高度按 `高 = 宽 ÷ 1.18` 计算。
2. 屏幕显示宽度上限 = **427 px**（1:1 原始像素）。超过 427 px 即为放大，而放大必然暴露噪点 → **禁止**；若确需更大尺寸，先按 Q1 取矢量母版。
3. 屏幕显示宽度下限见 2.6。
4. 缩放重采样只允许使用双三次（bicubic）或 Lanczos；禁止最近邻、禁止先放大再缩小。

### 2.3 留白（安全区）

1. 以裁切后椭圆高度 `H` 为基准，logo 四周安全区宽度 = **0.25 × H**。
2. 当前素材 `H = 362 px`，对应安全区 = **90.5 px**（在 1:1 使用时）。缩放到宽度 `W` 时，安全区 = `0.25 × W ÷ 1.18`。
3. 任何文字、图标、按钮、边框、分割线不得进入安全区（判定：以椭圆外接框向外各扩 0.25H 形成矩形，该矩形内除 logo 外必须为空）。
4. 安全区内的底色必须是纯白（见 2.4），不得有图案、渐变、阴影。

### 2.4 背景

1. **只允许**两种背景：纯白 `#FFFFFF`；或明度足够的浅色（判定：背景色与 `#062657` 的明度差 ≥ 60%，且背景本身亮度 L\* ≥ 90）。
2. **禁止**把 logo 放在深色、彩色、照片、纹理、渐变背景上 —— 当前文件没有透明通道，贴上深色底会露出**白色矩形（未裁切时）或椭圆四角的白色三角（裁切后）**，两种情况都已在深灰底上实测复现（`docs/brand/_probe-dark-bg.png`）。
3. **禁止**把 logo 放在与 `#062657` 相近的底色上（判定：底色与 `#062657` 的色差 ΔE < 20 即禁止），否则椭圆边界消失、只剩白色字形。
4. 若某场景确需深色背景，必须先解决 Q2（透明底），未确认前不得使用。

### 2.5 配色

1. 只允许使用素材自带的两个颜色：椭圆底 `#062657`、字形 `#FFFFFF`。
2. **禁止**任何形式的改色：换色、调色、加饱和度、加透明度、加渐变、加描边、加阴影/发光/立体效果、加噪点或纹理叠加。
3. 取色校验方法：对输出文件取椭圆内 5 个点、字形上 5 个点，颜色必须落在 `#062657` ±1 与 `#FFFFFF` ±1 的范围内（容许压缩误差）。

### 2.6 最小可用尺寸

由对当前文件的等比缩小实测得出（缩小样张见 `docs/brand/_probe-sizes.png`，该图为检查用，不是交付物）：

| 显示宽度 | 实测可读性 | 结论 |
|:---|:---|:---|
| 256 px | `ink` 完整清晰 | 允许 |
| 128 px | `ink` 完整清晰 | 允许 |
| 96 px | `ink` 完整清晰 | 允许 |
| 64 px | `ink` 可完整辨认 | **允许的最小值** |
| 48 px | 可辨认但笔画已粘连 | 仅在无替代方案时使用，且不得同时出现其它品牌标识 |
| 32 px 及以下 | 只能识别"深色椭圆 + 白色笔迹"轮廓，单字不可读 | **禁止**用于任何需要读清名称的位置；如需此尺寸的应用图标，必须另行提供简化版（Q3） |

1. 屏幕显示：logo 宽度 **≥ 64 px**。
2. 若用于印刷（属未确认场景 Q13）：等效宽度 ≥ 15 mm，且必须先取得矢量母版（Q1）。
3. 任何尺寸下都不得裁剪椭圆主体、不得只取字形部分使用。

### 2.7 排布与对齐

1. 单独使用时：logo 在容器内水平居中、垂直居中。
2. 与文字并排使用时：文字基线与椭圆垂直中线对齐（判定：椭圆的上下边界中点在文字行高的垂直中点 ±2 px 内）。
3. logo 与相邻文字/图形的间距 ≥ 安全区宽度（0.25 H）。
4. 不得为对齐而拉伸、倾斜或旋转（旋转仅允许 0°，其它角度需另出图，Q6）。

## 三、禁止事项

每条格式为：**禁止 → 判定方法 → 正确做法**。

| 编号 | 禁止事项 | 判定方法 | 正确做法 |
|:---|:---|:---|:---|
| P1 | 拉伸 / 压扁 / 非等比缩放 | 量出输出宽高比，偏离 1.18 : 1 超过 1% | 等比缩放，高度按 `宽 ÷ 1.18` 计算 |
| P2 | 倾斜、旋转、透视变形、3D 翻转 | 椭圆长轴与画布水平线的夹角 ≠ 0° | 只允许 0°；需要其它角度时另出图（Q6） |
| P3 | 改色：换主色、改白字颜色、加饱和度/透明度 | 2.5 的取色校验不通过 | 只保留 `#062657` + `#FFFFFF` |
| P4 | 加渐变、描边、投影、发光、立体、浮雕效果 | 椭圆边缘出现非抗锯齿的过渡带或偏移阴影 | 保持扁平原样 |
| P5 | 添加任何文字（含域名、slogan、`®`/`™`、版本号） | 画面内出现原始图像之外的字形 | 文字放在 logo 外部、安全区之外（标注需 Q10 确认） |
| P6 | 添加任何图形元素（圆点、边框、底板、印章、水印、二维码） | 画面内出现原始图像之外的形状 | 保持纯素材 |
| P7 | 改变比例或重新排布内部元素（如把墨点移走、把 `ink` 三个字母间距重排、重排字与椭圆的关系） | 与原始裁切图做像素级叠合比对，出现结构性位移 | 整张图作为不可分割的整体使用 |
| P8 | 重绘 / 用其它字体临摹 `ink` 字样 | 字形轮廓与原始图不一致 | 只用原始位图；需要矢量时走 Q1 |
| P9 | 把白底当透明底使用（贴到深色或彩色背景上不处理） | 输出图里能看到白色矩形，或椭圆四角的白色三角 | 按 2.4 只用浅色底，或先解决 Q2 |
| P10 | 放大超过 1:1（427 px 宽） | 输出宽度 > 427 px | 按 2.2 上限执行，或先取矢量母版 |
| P11 | 低于 64 px 使用（或低于 48 px 且出现在多品牌并排处） | 输出宽度 < 64 px | 改用合格尺寸，或等待简化版（Q3） |
| P12 | 裁掉椭圆任一部分（圆形裁切、只留字形、切角） | 椭圆轮廓不完整 | 整椭圆完整保留，按 2.1 仅裁白边 |
| P13 | 镜像 / 水平或垂直翻转 | 字形方向与原始图相反 | 不翻转 |
| P14 | 放在与 `#062657` 相近的底色上导致边界消失 | 底色与 `#062657` 的 ΔE < 20 | 换浅色底，或加白色安全区（2.3） |
| P15 | 把该 logo 用于商标注册、暗示官方背书、或声明超出项目自身的授权 | 出现在第三方授权/背书语境 | 按 Q11 处理，未确认前不授权他人使用 |
| P16 | 未经确认就产出衍生格式（透明版、ICO、单色版、横版） | 交付物里出现本规范未列出的文件 | 先确认 Q2/Q3/Q7/Q8/Q9 |
