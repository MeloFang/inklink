# 浮条可见性手测清单（2.0.x 底座稳定性验收）

> 目的：M3 动工前确认浮条（进程内自绘那条）在多应用/多线程场景下不出鬼。
> 三条都过 = 2.0 底座稳定，开 M3；任何一条不过 = 记下现象，先修再开。
>
> 测的时候开着日志最好：`C:\Users\Public\inklink-tsf-<进程号>.log` 里有
> `bar show/hide` 记录，出问题把日志给我。

## 准备

- 确认版本：浮条 ☰ → 关于，或看 `C:\Program Files\inklink\` 里的 DLL 名（应为 2.0.7）
- 准备两个日常 GUI 应用（建议：微信 + WPS；或 Edge + 记事本）
- 计数可以用手机，或者干脆按 10 下 × 3 轮数

## 用例 1：双应用切换 30 次

**操作**：在两个应用之间用鼠标/Alt+Tab 交替切换，共 30 次，每次等约 0.7 秒。

**期望**：
- 每次切换后，**前台恰好一条浮条**
- 后台那个应用里**零条**（不残留）

**记录**：第几次出现异常、当时哪两个应用、现象（两条 / 零条 / 位置错）。

## 用例 2：多 TSF 线程应用切入切出 30 次

**操作**：选一个含多个 TSF 线程的应用（Office / WPS / Edge 都算）。
Win+Space 切到 inklink（记 30 次），再切走（记 30 次）。

**期望**：
- 切入：激活后浮条出现一条
- 切出：浮条消失，不残留

**记录**：同上。

## 用例 3：Alt+Tab 与 Win+Space 快速交错

**操作**：10 秒内快速交错按 Alt+Tab 和 Win+Space，重复 5 轮。

**期望**：
- **不允许**出现两条浮条叠着
- 宿主应用不崩溃、不卡输入

**记录**：出现两条的那一轮做了什么。

## 结果怎么交

三条各回一行，比如：

```
用例1：30/30 通过
用例2：28/30，第 17、23 次切出后浮条残留在 WPS
用例3：通过
```

有异常的把 `C:\Users\Public\inklink-tsf-*.log` 最新那份发我。
