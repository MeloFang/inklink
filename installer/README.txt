inklink 输入法 __INKLINK_VERSION__  测试版
============================

一个开源的 Windows 中文输入法。注意：这是早期测试版，欢迎反馈问题。

版本号怎么读（X.V.Z）：
  X = 里程碑   0 = M0 能打字   1 = M1 个人词库   2 = M2 Obsidian 语料   3 = M3 AI
  V = 里程碑内的阶段序号
  Z = 修订号，每发一次版 +1；进入新阶段或新里程碑时归零
  例：0.1.22 = M0 第 1 阶段第 22 次修订；M1 的第一个版本是 1.0.0


安装
----

1. 解压到一个目录（不要在压缩包里直接运行）
2. 右键 install.cmd -> 以管理员身份运行
3. 看到「安装完成」后，按 Win+Space 切换到「inklink 输入法」
4. 如果输入法列表里还没有，重启一次电脑


右下角的浮条
------------

浮条**平时不出现**，只在切到这个输入法的时候才出来（和搜狗一样）；切到别的输入法
（或者按 Ctrl+空格 换成英文输入）它自己就收起来了。四格：

  【i】          品牌标记，点它等于点最右边的 ☰。

  【中】/【英】  点一下切换中文/英文。这是**全局**的：在微信里切成英文，
                 记事本、浏览器也一起变英文（不用每个软件各切一次）。
                 用 Shift 单击切换时，这个方块会跟着变。
  【，。】/【, .】点一下切换「中文标点」。关掉之后打的 `,` `.` `;` `?`
                 全部是英文半角（写代码时有用）。数字后面的标点永远是半角。
  【☰】          菜单（设置台还没做，见下面的「还没做」）。

  - 按住可以**拖到任意位置**，松手就记住，下次开机还在那儿。
  - 浮条就画在你正在打字的软件里（和搜狗一样），切到别的输入法就自动收起；
    没有常驻的浮条程序，任务栏/托盘里也不会多出图标。
  - 中英状态、中文标点都存在系统里（全局），切走再切回来还保持；浮条只是个
    状态显示和开关入口，不是输入法本体。


怎么打字
--------

  拼音输入        xiangmu          -> 项目                  打的时候会按音节显示成 xiang'mu（只是显示，不用管，
                  也不用打那个撇号；打 `-` 或 `_` 才会真的按它断音节）
  长句输入        wolaishuoshuo    -> 我来说说
  打错一点也能纠  niihao           -> 你好（多打一个字母）
                  jintain          -> 今天（两个字母打反了）
                  zhemge           -> 这个（多打一个字母）
                  shanghhai        -> 上海（多打一个字母）
                  末尾少打一个音    zheg / xiangm    -> 这个 / 项目
  打坏一串也不怕    shashahs         -> 傻傻还是…（中文排前，要英文按 Shift 或回车）
  分段上屏        pikeqiu          选「皮」之后剩下的 keqiu 留在候选窗里，
                                   可以接着选「克」「球」；多打的字母自动丢掉
  记住你的选择    xiangmu          第一次「项目」在前，你选了「橡木」之后
                                   「橡木」就排到前面去了（详见下面「个人词库」）
  整句也会学      分两次选一句话    jintiantianqi 先选「今天」再选「天气」，
                                   以后打同样的全拼，整句候选往前排
  想让音节断开    xi'an / xi-an     xian 是「先」，xi'an 是「西安」
                                   （打 `-` 或 `_` 也行；选过一次以后会记住）
  空格            上屏当前高亮的候选
  鼠标左键        直接点候选窗里的字就选它（点哪格选哪个）
  数字键 1-5      选「当前那一行」的第 N 个候选
  ↓ 或 =          候选窗展开成 5x5
  ↑ ↓             展开后换行
  ← →            展开后行内左右选；收起时移动拼音光标
  - =  / PgUp PgDn  展开后翻页
  Esc             取消这次输入
  回车           拼音原样上屏（当英文）
  Shift/CapsLock  拼音原样上屏（当英文）
  \               顿号「、」
  , . ; /         自动转成中文标点「，。；、」
                  但**前面是数字时出半角**：3.14、1,000、10:30
  Shift+1 ~ 0     全角符号「！＠＃￥％……＆＊（）」
  ' 和 "          中文引号，按一下开、再按一下合「‘’」「“”」
  - = _ +         永远是半角，不做中文转换（Excel 公式 =A1-B1 能直接用）
  -  (拼写中)     真正断开音节：xiang-mu / xiang_mu，显示成 xiang'mu
  按住 Shift      临时打英文（标点也保持英文）

  点鼠标到别处 = 取消当前输入（拼音不残留）


  选错了怎么办
  ------------
  上屏之后 2 秒内把刚打出来的那几个字删掉（连续按退格），输入法就知道你选错了，
  这次的选择不会再被记住。单字（只选了一个字）不学习，不会污染候选。

  分几次选完的一句话也一样：删掉最后那几个字只撤回那个词，一直删到整句都没了，
  整句那条记录也会一起撤掉。

  不同软件里各记各的：在微信里选的词只影响微信，不会把写代码时候选顶乱
  （同一个拼音在不同软件里各有各的排序，记的账是分开的）。

  个人词库在：%LOCALAPPDATA%\inklink\user-words.tsv
  想全部重来：关掉正在打字的程序，删掉这个文件即可（下次打字会重建）。

注意
----

- 刚装完第一次打字可能没反应，等 2-3 秒再打一次（引擎在加载词库）
- 已经在运行的软件需要重启一次才能用上（DLL 已被加载，不支持热替换）
- 词库约 54 万词，自带语言模型；不联网，不收集任何输入内容
- 拼音打一半也能出词：zheg / zhge / xiangm 都能出「这个 / 项目」
- 真英文词（hello、github、world）会把英文放在第一个候选，直接空格上屏


卸载
----

右键 uninstall.cmd -> 以管理员身份运行。


文件说明
--------

  C:\Program Files\inklink\
      inklink_tsf.dll      64 位输入法组件（记事本/VSCode/浏览器等）
      inklink_tsf32.dll    32 位输入法组件（WPS 等 32 位软件）

  C:\inklink-engine\
      rime-server.exe      引擎（用 librime）
      rime.dll             librime 本体
      rime\data\           词库与配置
      rime\user\           引擎配置（模糊音等）与构建产物
      rime-server.log      引擎日志（出问题时看这个）

  个人词库（你选过的词）
      %LOCALAPPDATA%\inklink\user-words.tsv
      记的是「你选了哪个词」，用它把常用的词顶到候选前面。
      纯本地、不联网、不上传。想从头再来就直接删掉这个文件
      （路径在文件资源管理器地址栏输入 %LOCALAPPDATA%\inklink 回车就能打开）。
      格式是「词码 <Tab> 词 <Tab> 次数」，一行一条，可以用记事本看和改。


遇到问题
--------

安装/卸载出问题
  日志文件：C:\Users\Public\inklink-install.log
            C:\Users\Public\inklink-uninstall.log
  直接把这个文件发给开发者，里面记录了系统版本、每一步做了什么、卡在哪。

  如果双击 install.cmd 完全没反应：
    a) 先确认是从解压后的文件夹里运行的，不是压缩包的预览窗口里
    b) 右键 install.cmd -> 属性 -> 如果底部有「解除锁定」，勾上确定后再试
    c) 右键 install.cmd -> 以管理员身份运行（不要直接双击）
    d) 都不行就手动开一个管理员 PowerShell，执行：
         cd /d 你解压的目录
         powershell -ExecutionPolicy Bypass -File install.ps1

打字出问题
  1. 引擎日志：C:\inklink-engine\rime-server.log
  2. 输入法没反应：确认 rime-server.exe 在任务管理器里；没有就双击
     C:\inklink-engine\rime-server.exe
  3. 某个软件里用不了：告诉我软件名和它的位数（64 位一般没问题）

模糊音（可选，默认关）
----------------------

普通话不分 zh/z、ch/c、sh/s，或者 in/ing、en/eng、n/l 分不清的，可以打开模糊音。
默认是关的 —— 因为我们实测发现：开了之后打 zi 第一个候选会从「子」变成「之」，
打 cang 会从「仓」变成「长」，对打字准的人反而是负担。

打开方法：
  1. 用记事本打开
     C:\inklink-engine\rime\user\luna_pinyin_simp.custom.yaml
     （没有这个文件就新建一个）
  2. 找到 patch: 下面 speller/algebra: 的 __patch: 列表，
     把想开的那组加进去，例如要开 zh/z 和 in/ing：
         patch:
           speller/algebra:
             __patch:
               - pinyin:/zh_z_bufen
               - pinyin:/en_eng_bufen
               - pinyin:/abbreviation
               - pinyin:/spelling_correction
               - pinyin:/key_correction
     注意模糊音必须排在 pinyin:/abbreviation 前面。
  3. 重启引擎：任务管理器里结束 rime-server.exe，
     再双击 C:\inklink-engine\rime-server.exe

七组可选：
  zh_z      zh/z  ch/c  sh/s 不分
  n_l       n/l 不分
  r_l       r/l 不分
  r_y       r/y 不分（人/银 这类）
  f_h       f/h 不分
  eng_ong   eng/ong 不分
  en_eng    en/eng 和 in/ing 不分


更新到新版本
------------

如果你已经装过旧版，更新只需要：

1. 关掉所有正在运行的软件（或者直接重启电脑）
2. 右键 install.cmd -> 以管理员身份运行
3. 完成

安装脚本会自动处理"旧 DLL 被占用"的情况（改用带时间戳的新文件名），
不需要先卸载。更新后同样需要重启正在用的软件。
