inklink __INKLINK_VERSION__ 同事使用说明
==============================

一、先看这里：你的电脑装过旧版吗？
--------------------------------
如果「设置 → 应用 → 已安装的应用」里**找不到**「inklink 输入法」，但电脑上以前装过 inklink，
说明装的是 2.2.3 或更早版本（那些版本没写卸载登记）。请：

  1) 右键「旧版清理工具\cleanup-old.cmd」→ 以管理员身份运行
  2) 清理完成后再看下面的「二、安装」

如果本来就没装过，或者应用列表里已经有「inklink 输入法」，直接跳到「二、安装」。

二、安装
--------
1. 把整个压缩包解压到本地文件夹（不要直接在压缩包里双击）。
2. 双击 inklink-__INKLINK_VERSION__-setup.exe，允许管理员权限。
3. 安装器自带 x86 VC++ 运行库，最后会实测一次拼音查询；
   看到「引擎实测通过」才算装好。
4. 按 Win+Space 切到「inklink 输入法」，打 nihao，按空格选「你好」。
5. 已经打开着的微信、WPS、浏览器要重启一次（它们还加载着旧 DLL）。

三、卸载
--------
装好之后：设置 → 应用 → 已安装的应用 → 搜「inklink 输入法」→ 卸载。
卸载命令由安装器自身提供，不依赖压缩包里的其它文件。

四、基本操作
------------
- 空格选当前候选，数字键选对应候选。
- 单击 Shift 切中英文；Caps Lock 开着时临时出英文（浮条显示 A）。
- 拼音中间打半角撇号可指定音节边界，例如 na'ni、xi'an。
- 上屏后出现联想条时，按 1/2/3 或点击选择。
- 浮条菜单 → 设置：候选行列、外观、学习开关、联想条开关。

五、笔记词汇（可选）
--------------------
设置里填自己的 Obsidian 库或任意 Markdown 目录 → 点「立即导入」。
本机转换，不需要装 Python。改完笔记再点一次导入即可。

六、AI（可选）
--------------
设置里勾「启用 AI」，选 ollama（本机）或 openai（兼容 API）。
- ollama：填本机地址和模型名。
- openai：填接口地址、模型 ID、自己的 API Key。
AI 面板点「粘贴」会打开可滚动、可编辑的原文窗口，改完点「应用修改」。
开启远程 API 后，主动提交的原文会发到所填写的服务，请按单位要求使用。

七、出问题了
------------
双击安装目录里的 C:\Program Files\inklink\diagnose.cmd，
桌面会生成「inklink-诊断-<时间>.txt」，把它发回来即可定位。
「只有拼音、没有候选」时，重点看报告里的「管道实测」一节。

八、包内容与许可
----------------
- inklink-__INKLINK_VERSION__-setup.exe：安装程序（含 x86 VC++ 运行库副本）
- 旧版清理工具\cleanup-old.cmd / cleanup-old.ps1：清掉 2.2.3 及更早版本
- 使用说明.txt（本文件）、LICENSE.txt（GPL-3.0）、SHA256SUMS.txt（校验值）
- 不含开发者个人词库、笔记、实体关系、API Key 或设置
